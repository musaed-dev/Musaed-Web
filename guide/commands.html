01قبل ما تبدأ

كل أوامر مساعد أوامر سلاش: اكتب / واختار الأمر من القائمة.

  • الأمر يظهر لك بس لو عندك الصلاحية اللي يحتاجها، وإلا ديسكورد يخفيه عنك غالبًا.
  • الطرد والحظر والكتم والإنذار تحتاج صلاحية لك، وأغلبها يحتاج نفس الصلاحية لمساعد. وما تنفّذ على من رتبته فوق رتبتك أو فوق رتبة مساعد.
  • كل إجراء إداري ينسجل بسجل الإجراءات.

02قائمة الأوامر

  • /kickيحتاج Kick Members

    اطرد عضو من السيرفر ويتسجل بالسجل.

  • /banيحتاج Ban Members

    احظر عضو من السيرفر ويتسجل بالسجل. تقدر تحدد حذف رسايله، بمدة تكتبها هنا.

  • /unbanيحتاج Ban Members

    فك الحظر عن حساب بالايدي حقه.

  • /timeoutيحتاج Moderate Members

    اكتم عضو مدة محددة ويتسجل بالسجل. المدة تكتبها كذا.

  • /warnيحتاج Moderate Members

    أنذر عضو ويتسجل الإنذار بالسجل.

  • /modlogsيحتاج Moderate Members

    اعرض سجل الإجراءات الإدارية بالسيرفر.

  • /lookupيحتاج Moderate Members

    بطاقة وحدة عن عضو: إنذاراته وضربات الحماية وتواريخه.

  • /deletemsيحتاج Manage Messages

    احذف رسايل من القناة الحالية، وتقدر تخصها بعضو واحد. ما يحذف الرسايل الأقدم من 14 يوم، ويقولك كم رسالة تجاوزها.

  • /lockيحتاج Manage Channels

    اقفل القناة الحالية عن الأعضاء. القفل يبقى لين ما تفتحها بـ /unlock، ما فيه مؤقت.

  • /unlockيحتاج Manage Channels

    شِل قفل القناة الحالية وخل الأعضاء يكتبون فيها.

  • /captcha lockdownيحتاج Manage Server

    اخف كل القنوات عن غير المتحقق إلا قناة التحقق. الشرح.

  • /captcha unlockيحتاج Manage Server

    شِل قفل غير المتحقق عن كل القنوات.

  • /tickets setupيحتاج Manage Server

    حدد قناة اللوحة ورتبة الدعم وقناة السجل، وفعّل نظام التذاكر. الشرح.

  • /tickets panelيحتاج Manage Server

    غيّر النص اللي يظهر بلوحة فتح التذاكر.

  • /checkupيحتاج Administrator أو Manage Server

    افحص إعدادات السيرفر وشوف وش المعطل فيها. الشرح.

  • /welcome previewيحتاج Manage Server

    شوف شكل رسالة الترحيب على حسابك.

  • /prefix showيحتاج Administrator أو Manage Server

    اعرض بادئة الأوامر الحالية.

  • /prefix setيحتاج Administrator أو Manage Server

    غيّر بادئة الأوامر للسيرفر.

  • /prefix resetيحتاج Administrator أو Manage Server

    رجّع البادئة للوضع الافتراضي.

  • /serverinfoللكل

    معلومات عن السيرفر.

  • /whoisللكل

    معلومات عن عضو بالسيرفر.

  • /avatarللكل

    اعرض صورة عضو بالحجم الكامل مع روابط تحميلها.

  • /aboutيحتاج Administrator أو Manage Server

    دليل كامل لكل أوامر مساعد وطريقة استخدامها.

  • /musaedللكل

    تعرف على مساعد، وشوف رابط الإضافة وقائمة الأوامر. يشتغل حتى بالخاص.

ما فيه أمر يطابق بحثك. جرّب كلمة ثانية، أو اختار «الكل».

03كيف تكتب المدة

الأوامر اللي تطلب مدة (مثل /timeout) تاخذها كنص، مو رقم بس.

30m
30 دقيقة
1h30m
ساعة ونص. تقدر تجمع أكثر من وحدة.
7d
7 أيام
2w
أسبوعين
3mon
3 شهور. الشهر عندنا 30 يوم.
1y
سنة. السنة عندنا 365 يوم.
  • تقدر تكتبها بالعربي، مثل «30 يوم».
  • لو كتبت رقم بس، مساعد يفترض وحدة افتراضية: دقايق بـ /timeout، وأيام بخيار حذف الرسايل بـ /ban.
